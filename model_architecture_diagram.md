### 图2: Node Encoder详细结构（HeteroGAT）

```
Input: ñ(v) ∈ ℝ^768 (masked node features)
       ẽ(e) ∈ ℝ^768 (masked edge features)
       Graph structure: (V, E)

┌────────────────────────────────────────────────────────────────┐
│                 Heterogeneous GAT Layer 1                       │
│                                                                 │
│  For each relation type r = (τ_s, r, τ_t):                    │
│                                                                 │
│  ┌──────────────────────────────────────────────────────────┐ │
│  │  Multi-Head Attention (H=4 heads)                        │ │
│  │                                                           │ │
│  │  For head k ∈ {1,...,4}:                                │ │
│  │                                                           │ │
│  │  1. Attention Score:                                     │ │
│  │     e_uv^k = LeakyReLU(a_r^k ⊤ [W_r^k·ñ(u) ∥           │ │
│  │                                   W_r^k·ñ(v) ∥           │ │
│  │                                   U_r^k·ẽ(u,v)])         │ │
│  │                                                           │ │
│  │  2. Attention Weight:                                    │ │
│  │     α_uv^k = exp(e_uv^k) / Σ_{u'∈N_r(v)} exp(e_u'v^k)  │ │
│  │                                                           │ │
│  │  3. Message Aggregation:                                │ │
│  │     h_v^{r,k} = Σ_{u∈N_r(v)} α_uv^k · W_r^k·ñ(u)       │ │
│  │                                                           │ │
│  │  4. Multi-Head Concatenation:                           │ │
│  │     h_v^r = [h_v^{r,1} ∥ h_v^{r,2} ∥ ... ∥ h_v^{r,4}]  │ │
│  │           ∈ ℝ^1024 (256×4)                              │ │
│  └──────────────────────────────────────────────────────────┘ │
│                                                                 │
│  Multi-Relation Aggregation:                                   │
│  h_v^(1) = Σ_{r∈R_in(v)} h_v^r                                │
│                                                                 │
│  Activation: h_v^(1) = Dropout(ReLU(h_v^(1)), p=0.3)          │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
                            ↓
┌────────────────────────────────────────────────────────────────┐
│                 Heterogeneous GAT Layer 2                       │
│                                                                 │
│  For each relation type r:                                     │
│                                                                 │
│  Single-Head Attention (H=1):                                  │
│                                                                 │
│  α_uv = softmax(LeakyReLU(a_r⊤ [W_r·h_u^(1) ∥                │
│                                  W_r·h_v^(1) ∥                 │
│                                  U_r·ẽ(u,v)]))                 │
│                                                                 │
│  h_v^{r,2} = Σ_{u∈N_r(v)} α_uv · W_r·h_u^(1)                 │
│                                                                 │
│  z(v) = Σ_{r∈R_in(v)} h_v^{r,2} ∈ ℝ^256                      │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
                            ↓
                  Output: z(v) ∈ ℝ^256
```

### 图3: Edge Encoder详细结构（MLP-based）

```
Input: z(u), z(v) ∈ ℝ^256 (from Node Encoder)
       ẽ(e) ∈ ℝ^768 (masked edge static embedding)
       w(e) ∈ ℝ (edge weight, optional)

┌────────────────────────────────────────────────────────────────┐
│                    Feature Concatenation                        │
│                                                                 │
│  f_e = [z(u) ∥ z(v) ∥ ẽ(e) ∥ w(e)]                            │
│      = [256   256   768    1]                                  │
│      ∈ ℝ^1281                                                  │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
                            ↓
┌────────────────────────────────────────────────────────────────┐
│                      MLP Layer 1                                │
│                                                                 │
│  h_e^(1) = ReLU(W_e^(1) · f_e + b_e^(1))                      │
│          ∈ ℝ^256                                               │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
                            ↓
┌────────────────────────────────────────────────────────────────┐
│                        Dropout                                  │
│                                                                 │
│  h_e^(1) = Dropout(h_e^(1), p=0.3)                            │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
                            ↓
┌────────────────────────────────────────────────────────────────┐
│                      MLP Layer 2                                │
│                                                                 │
│  e_h(e) = W_e^(2) · h_e^(1) + b_e^(2)                         │
│         ∈ ℝ^256                                                │
│                                                                 │
└────────────────────────────────────────────────────────────────┘
                            ↓
                  Output: e_h(e) ∈ ℝ^256
```

### 表1: 模型配置参数

| Component | Parameter | Value | Description |
|-----------|-----------|-------|-------------|
| **Input** | $d_n$ | 768 | Node static embedding dimension |
|           | $d_e$ | 768 | Edge static embedding dimension |
|           | $\rho_n$ | 0.3 | Node masking rate |
|           | $\rho_e$ | 0.2 | Edge masking rate |
| **Node Encoder** | $H$ | 4 | Number of attention heads (Layer 1) |
|                  | $d_h$ | 256 | Hidden dimension per head |
|                  | $d_z$ | 256 | Node hidden embedding dimension |
|                  | Layers | 2 | Number of GAT layers |
|                  | Dropout | 0.3 | Dropout rate |
| **Edge Encoder** | $d_{e_h}$ | 256 | Edge hidden embedding dimension |
|                  | Layers | 2 | Number of MLP layers |
|                  | Dropout | 0.3 | Dropout rate |
| **Decoder** | Type | Linear | Decoder architecture |
|             | Input | $d_z$ or $d_{e_h}$ | Hidden embedding dimension |
|             | Output | $d_n$ or $d_e$ | Original dimension |
| **Loss** | $\lambda_e$ | 0.5 | Edge loss weight |
|          | Type | MSE | Loss function type |
| **Training** | Optimizer | Adam | Optimization algorithm |
|              | Learning rate | 1e-3 | Initial learning rate |
|              | Epochs | 20 | Training epochs |

### 关键设计特性说明

1. **双分支架构 (Dual-Branch)**:
   - Node分支：处理节点特征，使用异质图注意力网络
   - Edge分支：处理边特征，使用MLP（依赖节点hidden embeddings）

2. **异质图建模 (Heterogeneous Graph)**:
   - 每个节点类型和关系类型有独立的参数
   - 支持多种语义角色的建模

3. **Mask机制 (Masking)**:
   - 节点mask：30%的节点特征置零
   - 边mask：20%的边特征置零（保持图结构不变）
   - 自监督学习，无需人工标注

4. **注意力机制 (Attention)**:
   - 融合边特征到注意力计算
   - 多头机制捕获不同语义子空间
   - 异质关系独立处理后聚合

5. **非对称依赖 (Asymmetric Dependency)**:
   - Edge encoder依赖Node encoder的输出
   - 保证边表示具有结构上下文

6. **类型特定解码 (Type-specific Decoding)**:
   - 每个节点/边类型有独立的decoder参数
   - 适配不同分布和语义
