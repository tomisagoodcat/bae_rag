### Define
A **scientific dataset** (`whu:Data`) is a research artifact **generated by** or **used in** research activities.  
It is a subclass of **mp:Data**, **dcat:Dataset**, **prov:Entity**, and aligned with **bfo:GenericallyDependentContinuant**.  
Datasets can **support** or **challenge** `mp:Statement` / `mp:Claim` and have explicit provenance: linked to `whu:ActivityStep` via `prov:wasGeneratedBy` or `prov:used`.  
A dataset may appear as a **table, figure, or file**; parts (e.g., table rows) also count as `whu:Data` if they independently support/challenge a claim.  

---

### Purpose
- **Argumentation**: connect data to claims (`mp:supports`, `mp:challenges`).  
- **Measurement linkage**: associate with `whu:ScalarMeasurementDatum` (value, unit, comparator).  
- **Method dependency**: linked to `whu:Method` that generated it.  
- **Activity provenance**: used/produced by `whu:BioChemicalActivityStep` or `whu:ComputationalActivityStep`.  

---

### Context
Trigger `whu:Data` when text explicitly describes **data as a research artifact** (dataset, table, figure, measurement).  
- If dataset supports/challenges a claim → mark as `whu:Data`.  
- If a table/figure is indivisible → treat as single dataset.  
- If only scalar values are given, create `whu:ScalarMeasurementDatum` and link with `dcterms:hasPart`.  
- Activities that **use** and then **generate** data should always link datasets via provenance.  

---

### Semantic Links
- `whu:Data` → `mp:supports/challenges` → `mp:Claim` or `mp:Statement`  
- `whu:Data` → `dcterms:hasPart` → `whu:ScalarMeasurementDatum`  
- `whu:Method` → `mp:supports` → `whu:Data`  
- `whu:ActivityStep` → `prov:used/generated` → `whu:Data`  

---

### Examples
**whu:Data 1 — Rice MeHg Accumulation**  
- **Generated by**: field harvest and ICP-MS analysis of rice tissues (roots, stalks, leaves, grains).  
- **Supports claim**: biochar decreased MeHg accumulation, especially in grains.  

**whu:Data 2 — Porewater DOM Characteristics**  
- **Generated by**: fluorescence, UV-Vis, TOC analysis of porewater samples.  
- **Supports claim**: biochar altered DOM properties (↑ aromaticity, molecular weight, humic content), explaining MeHg production trends.
